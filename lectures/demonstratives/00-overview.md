# Demonstratives — Overview

The **こ/そ/あ/ど** family — Japanese's "this / that / that over there /
which?" set. There are several parallel series (これ, この, ここ,
こちら, こんな, …) and they all follow the same four-way distance
contrast.

This folder covers the two starter lectures:

1. [これ / それ / あれ / どれ — the basic series](01-kore-sore-are.md)
2. [これは vs これに — the particle pair you keep mixing up](02-kore-wa-vs-kore-ni.md)

The full こ/そ/あ/ど chart and the noun-modifying この/その/あの/どの
series will get their own lectures later.
