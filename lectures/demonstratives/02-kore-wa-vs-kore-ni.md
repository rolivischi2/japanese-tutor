# これは vs これに — the pair you keep mixing up

`これ` is a noun ("this thing"), and like any noun it can take **any**
particle. Two of those combinations carry a different meaning, and
beginners default to は everywhere because は is the first particle
they learn.

The fix:

- **これ は** = "**as for** this thing, …" — used when **this** is the
  **topic** of a statement.
- **これ に** = "**to / at / onto / into** this thing" — used when
  **this** is the **destination, time, or indirect-object target** of
  an action.

If you can replace に with English **"to / onto / into / at"**, you
need に. If you can replace は with **"as for"**, you need は.

## Side-by-side

### Pair 1 — what it is vs where you put something

> これ は ほん です。
> *This is a book.* (topic = "this") → **は**

> これ に かきます。
> *I'll write **on** this.* (target of writing = this) → **に**

### Pair 2 — what it costs vs what you add it to

> これ は たかい です。
> *This is expensive.* (comment about this) → **は**

> これ に さとう を いれます。
> *I'll put sugar **into** this.* (this = container target) → **に**

### Pair 3 — describing vs adding to

> それ は おちゃ です。
> *That's tea.* (topic = that) → **は**

> それ に ミルク を いれます。
> *I'll add milk **to** that.* (target = that) → **に**

### Pair 4 — talking about vs going there

> あの こうえん は ちかい です。
> *That park is close.* → **は**

> あの こうえん に いきます。
> *I'm going **to** that park.* → **に**

### Pair 5 — same noun, different verb

> これ は つくえ です。
> *This is a desk.*

> これ に ほん を おきます。
> *I'll put a book **on** this.* (this = the surface)

### Pair 6 — questioning

> これ は なん ですか。
> *What is this?* (asking about the thing — topic)

> これ に なに を いれますか。
> *What will you put **into** this?* (asking what fills the target)

### Pair 7 — time targets

`これ` doesn't naturally take に for time, but the same logic applies
to other words:

> しちじ は はやい です。
> *Seven o'clock is early.* (commenting on the time — topic)

> しちじ に おきます。
> *I get up **at** seven.* (target time → に)

## The replacement test

When you're unsure which particle:

1. Try the English **"as for"** in front of the noun. If it sounds
   right, use **は**.
2. Try English **"to / at / onto / into"** in front of the noun. If
   that sounds right, use **に**.
3. If both could fit, ask: **am I describing this thing, or am I
   pointing an action at it?** Description → は. Action target → に.

## Why beginners get this wrong

You learn は first. It works in nearly every M00–M01 sentence ("X
is Y"). The moment you add an action verb — おきます, いれます,
かきます, あげます, いきます — the noun you're acting **on** /
**into** / **to** wants に, not は. Old habit kicks in and you say
`これ は かきます`, which sounds (to a Japanese ear) like "as for this,
I write" — i.e. you're saying "this" is your topic, not your target.
