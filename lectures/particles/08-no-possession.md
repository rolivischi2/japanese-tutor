# の — possession and noun modification

The particle **の** glues two nouns together: the first noun describes,
owns, or characterises the second. The cleanest English gloss is
**"X's Y"** or **"Y of X"**.

## Pattern

```
N1 の N2  →  "N1's N2" / "N2 of N1"
```

The owner / descriptor comes first; the thing being owned / described
comes second. The opposite order of casual English ("the book of mine"
vs "**my** book") — Japanese puts the modifier first.

## Possession

> わたし の ほん。
> *My book.*

> あなた の くるま。
> *Your car.*

> ともだち の いえ。
> *My friend's house.*

> せんせい の かばん。
> *The teacher's bag.*

## Description / type

の also marks **what kind** of thing it is — language of a book, country
of origin, material, etc.

> にほんご の ほん。
> *A Japanese-language book.* (a book of Japanese)

> にほん の たべもの。
> *Japanese food.* (food of Japan)

> ドイツ の くるま。
> *A German car.*

> こども の ふく。
> *Kids' clothes.* (clothes for / of children)

## In a full sentence

> これ は わたし の ほん です。
> *This is my book.*

> それ は にほんご の じしょ です。
> *That's a Japanese dictionary.*

> あの ひと は ともだち の おとうさん です。
> *That person is my friend's father.*

## Chaining の

You can stack の to drill down — each の adds one more layer of
ownership/description. Read right-to-left to get the English order.

> ともだち の おとうさん の くるま。
> *My friend's father's car.*

> にほん の だいがく の せんせい。
> *A teacher at a Japanese university.* (lit. "Japan's university's teacher")

> わたし の あね の かれし。
> *My older sister's boyfriend.*

Don't chain more than two or three — it gets unreadable fast.

## Standing alone

When context makes the second noun obvious, you can drop it. の acts
like English "mine / yours / Yamada's".

> この ほん は わたし の です。
> *This book is mine.* (the second noun ほん is implied)
