# を — the direct-object marker

The particle **を** marks the **direct object** of a verb — the thing
that the action is being done to. "I eat **bread**" → bread is what
gets eaten, so bread takes を.

> Pronunciation: を is read **"o"** in modern Japanese, identical to
> the kana お. It exists as a separate kana only because it is reserved
> for this particle — you will (almost) never see it inside a normal
> word.

## Pattern

```
[subject] は [object] を [verb] 。
```

The subject (often わたし) frequently gets dropped when it's clear from
context, but the **object を verb** unit is the heart of the sentence.

## Examples

> パン を たべます。
> *I eat bread.*

> みず を のみます。
> *I drink water.*

> ほん を よみます。
> *I read a book.*

> てがみ を かきます。
> *I write a letter.*

> えいが を みます。
> *I watch a movie.*

> にほんご を べんきょう します。
> *I study Japanese.*

## Subject + object together

> わたし は コーヒー を のみます。
> *I drink coffee.*

> はは は ごはん を つくります。
> *My mother makes the meal.*

> がくせい は しゅくだい を します。
> *Students do homework.*

## Note on motion verbs

A small number of motion verbs use を for the **path** rather than the
object — e.g. みち を あるきます ("walk along the road"). Don't
worry about that yet; it shows up later. For now, treat を as "direct
object".
