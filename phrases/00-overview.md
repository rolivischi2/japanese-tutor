# Phrases — Overview

High-frequency everyday Japanese, categorised for fast browsing. Each
file groups closely-related expressions; kana on the first line, English
gloss in italics below.

These are **set phrases** — memorise the whole pattern. Don't try to
break every one of them down grammatically; some (especially fixed
greetings) come from older registers that don't follow textbook rules.
