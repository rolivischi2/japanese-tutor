# これ・それ・あれ・どれ — A Preview

This file gives you just enough of the demonstrative system to talk about
objects in Module 01 dialogues. The **full こそあど system** — including この/その,
ここ/そこ, こんな/そんな and more — is Module 02. Here you learn only the four
*"this one / that one"* words.

## The four words

| Word | Meaning | Where the thing is |
|---|---|---|
| これ | this one | near **me** (the speaker) |
| それ | that one | near **you** (the listener) |
| あれ | that one over there | away from **both** of us |
| どれ | which one? | (the question word) |

These are **pronouns** — they stand in for a noun, like English "this / that /
which one." They drop straight into the `N は N です` frame.

## The こ / そ / あ / ど logic

Notice the shared shape: only the **first mora** changes, and it encodes
distance:

- **こ**れ — the **こ** zone: by the speaker.
- **そ**れ — the **そ** zone: by the listener.
- **あ**れ — the **あ** zone: away from both.
- **ど**れ — the **ど** slot: the question ("which?").

Every こそあど series in Module 02 reuses this same こ/そ/あ/ど logic, so getting
it now makes Module 02 almost free.

## それ ≠ "that" from English

English splits the world into two ("this" near me / "that" everything else).
Japanese splits it into **three**, and the middle one is anchored to the
**listener**, not just "medium distance":

- これ — in my hand, on my side of the table.
- それ — in your hand, on your side of the table.
- あれ — over on the far wall, away from us both.

So **それ** is "that thing by you," and **あれ** is "that thing over there away
from us." Mapping both onto English "that" will trip you up — keep the
three-way speaker / listener / elsewhere split.

## どれ — "which one?"

どれ asks the listener to pick one out of several:

> どれ が あなた の かばん です か。
> Which one is your bag?

This is the only place where you will naturally meet **が** in Module 01. With
question-word subjects like どれ, Japanese uses が, not は — you cannot make a
*topic* out of "which?", because which one it is is exactly the unknown. Just
accept どれ が… as a fixed pattern for now; the は/が contrast is Module 02.

Answer どれ questions with **これ / それ / あれ**:

> — これ です。
> — This one.

## Examples

> これ は ほん です。
> This is a book.

> それ は あなた の スマホ です か。
> Is that (by you) your smartphone?

> あれ は なん です か。
> What is that over there?
> — あれ は カメラ です。 — That is a camera.

> これ は コーヒー です。それ は おちゃ です。
> This is coffee. That (by you) is tea.

> どれ が マリオさん の かばん です か。
> Which one is Mario's bag?
> — あれ です。 — That one over there.

**Note — なん / なに ("what").** あれ は なん です か ("What is that?") uses
なん, the question word for "what." It is in this module's vocab as a useful
companion to the demonstratives; the full set of question words comes later.

## Common mistakes

| ✗ Wrong | ✓ Right | Why |
|---|---|---|
| using それ for "that over there" | あれ | それ is by the **listener**; あれ is far from both. |
| これ は です か | これ は **なん** です か | A question needs a question word or a noun before です か. |
| どれ **は** … | どれ **が** … | Question-word subjects take が, not は. |
| treating これ as an adjective ("this book") | これ stands **alone** | これ = "this one." "This book" (この ほん) is Module 02. |

## One thing this file does NOT cover

You cannot yet say "**this** book" as a phrase — that needs **この**, which is
Module 02. For now これ/それ/あれ/どれ only ever stand **alone** as "this
one / that one / which one." If you want to point at a specific book in a
Module 01 dialogue, say これ は ほん です ("this is a book"), not "この ほん."

## Pronunciation

All four are 2-mora words read flat and even: こ・れ / そ・れ / あ・れ / ど・れ.
Keep both morae equally loud — resist any instinct to thump the first mora.
(Hungarian L1 speakers: see `pronunciation/07-hungarian-transfer-notes.md`.)

## Quick check

Fill the blank with これ / それ / あれ / どれ.

1. (a thing in your own hand) ____ は スマホ です。
2. (a thing in the listener's hand) ____ は あなた の ほん です か。
3. (asking the listener to choose) ____ が コーヒー です か。

> 1. これ
> 2. それ
> 3. どれ
