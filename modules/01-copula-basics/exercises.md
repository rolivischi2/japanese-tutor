# Module 01 — Exercises

Work through each section, write your answers, then check against the **answer
key** at the bottom. Everything is kana — no romaji, no kanji. Sections marked
*(model answer)* depend on your own true facts; check the **structure**, not the
exact words.

---

## Section A — です affirmative

Translate into Japanese. Use `N は N です`.

A1. I am an engineer.
A2. This is a book.
A3. Mika is a teacher.
A4. I am Swiss.
A5. Mario is a student.
A6. Today is a day off.
A7. I am thirty-seven years old. *(careful — number + さい)*
A8. I am twenty years old. *(careful — irregular!)*

---

## Section B — Negatives with じゃありません

Rewrite each sentence as a negative, using **じゃありません**.

B1. わたし は がくせい です。
B2. これ は コーヒー です。
B3. マリオ は にほんじん です。
B4. わたし は せんせい です。
B5. それ は わたし の かばん です。
B6. あれ は にほん の カメラ です。

---

## Section C — The register spectrum

Each sentence below means "Mika is not a teacher." Label each form as
**formal**, **polite spoken**, **conversational polite**, or **plain (casual)**.

C1. ミカさん は せんせい ではありません。
C2. ミカさん は せんせい じゃありません。
C3. ミカさん は せんせい じゃないです。
C4. ミカさん は せんせい じゃない。

C5. Of C1–C4, which two are the best choices for a polite tutor session?

---

## Section D — Questions with か

Turn each statement into a yes/no question.

D1. あなた は がくせい です。
D2. これ は パン です。
D3. あれ は あなた の スマホ です。
D4. ミカさん は にほんじん です。

Now answer each question with a **full sentence**.

D5. あなた は エンジニア です か。 *(model answer — answer truthfully)*
D6. これ は チーズ です か。 *(it is bread)*
D7. あなた は にほんじん です か。

---

## Section E — の (possession and noun-modification)

Translate into Japanese using の.

E1. my book
E2. Mika's smartphone
E3. a Japanese car
E4. This is my bag.
E5. Is that your camera?
E6. Mario is my friend.
E7. This one is mine. *(let の stand alone — the noun is understood)*

---

## Section F — これ / それ / あれ / どれ

Fill the blank with the right demonstrative.

F1. (a thing in your own hand) ____ は スマホ です。
F2. (a thing in the listener's hand) ____ は あなた の ほん です か。
F3. (a thing far from you both) ____ は カメラ です。
F4. (asking the listener to pick one) ____ が ミカさん の かばん です か。

---

## Section G — Spot the mistake

Each sentence has exactly one error. Write the corrected sentence.

G1. わたし が エンジニア です。
G2. わたし は がくせい でする。
G3. これ わたし の ほん です。
G4. か です あなた がくせい。
G5. わたし は いきますです。
G6. ほん わたし の です。

---

## Section H — Build a self-introduction

Write **five** sentences introducing yourself, using only Module 01 grammar:
name, nationality, age, occupation, and one negative ("I am not a ___").
There is no single answer key — the model in the key shows one valid version.

## Section B

B1. わたし は がくせい じゃありません。
B2. これ は コーヒー じゃありません。
B3. マリオ は にほんじん じゃありません。
B4. わたし は せんせい じゃありません。
B5. それ は わたし の かばん じゃありません。
B6. あれ は にほん の カメラ じゃありません。

## Section C

C1. **formal / written** (ではありません)
C2. **polite spoken** (じゃありません)
C3. **conversational polite** (じゃないです)
C4. **plain / casual** (じゃない) — Module 06; recognise only, don't produce yet.
C5. **C2 (じゃありません)** and **C3 (じゃないです)** — both are polite and
    natural in spoken Japanese. C1 is fine but a little stiff; C4 is too casual
    for a tutor lesson.

## Section D

D1. あなた は がくせい です か。
D2. これ は パン です か。
D3. あれ は あなた の スマホ です か。
D4. ミカさん は にほんじん です か。
D5. *(model)* はい、エンジニア です。 / いいえ、エンジニア じゃありません。
D6. いいえ、チーズ じゃありません。パン です。
D7. *(model)* いいえ、にほんじん じゃありません。スイスじん です。

## Section E

E1. わたし の ほん
E2. ミカさん の スマホ
E3. にほん の くるま
E4. これ は わたし の かばん です。
E5. それ は あなた の カメラ です か。
E6. マリオ は わたし の ともだち です。
E7. これ は わたし の です。

## Section F

F1. これ
F2. それ
F3. あれ
F4. どれ *(question-word subject — note か takes が, not は)*

## Section G

G1. わたし **は** エンジニア です。 — Module 01 uses は (topic), not が.
G2. わたし は がくせい **です**。 — です takes no extra ending; でする is wrong.
G3. これ **は** わたし の ほん です。 — don't drop the topic particle は.
G4. **あなた は がくせい です か。** — no reordering; か just goes last.
G5. わたし は **いきます**。 — です never attaches to a verb. ✗いきますです.
G6. **わたし の ほん** です。 — owner first: *owner + の + thing*.

## Section H — model self-introduction

> はじめまして。わたし は アレックス です。
> わたし は スイスじん です。
> わたし は さんじゅうなな さい です。
> わたし は エンジニア です。
> わたし は せんせい じゃありません。

Your version will use your own facts — that is the point. Check that every
sentence is `N は N です` or `N は N じゃありません`, that は is read "wa," and
that no です landed on a verb.
