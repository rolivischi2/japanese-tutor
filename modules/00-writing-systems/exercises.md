# Module 00 — Exercises

Kana reading and writing-recognition drills. There is **no romaji** here — the point of the module is to read kana, so answers are given in kana, IPA, or English. Work through each exercise with the answer key covered; the full key is at the bottom.

These are paper-style drills for checkpointing your knowledge. Day-to-day *speed* building happens on realkana.com and in your Anki kana deck — these exercises confirm you actually know the system, not just that you can pattern-match a flashcard.

# Answer Key

## Section A

**A1.** あ [a] ・ き [ki] ・ す [sɯ] ・ て [te] ・ の [no] ・ ふ [ɸɯ] ・ む [mɯ] ・ ら [ɾa] ・ を [o] ・ ん [n] (moraic nasal, place varies)

**A2.** 1. あか — "red" ・ 2. こえ — "voice" ・ 3. すし — "sushi" ・ 4. ひと — "person" ・ 5. ふね — "boat" ・ 6. やま — "mountain" ・ 7. ゆめ — "dream" ・ 8. さくら — "cherry blossom" ・ 9. わたし — "I / me" ・ 10. ほん — "book"

**A3.** 1. ねこ — 2 morae ・ 2. ほん — 2 morae (ほ + ん) ・ 3. さくら — 3 morae ・ 4. わたし — 3 morae

## Section B

**B1.** が [ga] ・ じ [(d)ʑi] ・ ず [(d)zɯ] ・ で [de] ・ ど [do] ・ ば [ba] ・ ぴ [pi] ・ ぷ [pɯ] ・ ぺ [pe] ・ ご [go]

**B2.** 1. か → が ・ 2. し → じ ・ 3. つ → づ ・ 4. ほ → ぼ (dakuten) / ぽ (handakuten) ・ 5. へ → べ (dakuten) / ぺ (handakuten)

**B3.** 1. かぎ — "key" ・ 2. みず — "water" ・ 3. でんわ — "telephone" ・ 4. だれ — "who" ・ 5. ぱん — "bread" ・ 6. えんぴつ — "pencil" ・ 7. さんぽ — "a walk / a stroll"

**B4.** 1. ば = dakuten (b-sound), ぱ = handakuten (p-sound) ・ 2. び = dakuten (b-sound), ぴ = handakuten (p-sound)

## Section C

**C1.** きゃ [kja] ・ しゅ [ɕɯ] ・ ちょ [tɕo] ・ にゃ [ɲa] ・ ひゅ [çɯ] ・ りょ [ɾjo] ・ じゃ [(d)ʑa] ・ びょ [bjo] ・ ぴゅ [pjɯ]

**C2.** 1. きゃく — 2 morae (きゃ + く) ・ 2. きやく — 3 morae (き + や + く; large や) ・ 3. きょう — 2 morae (きょ + う) ・ 4. でんしゃ — 3 morae (で + ん + しゃ) ・ 5. りょこう — 3 morae (りょ + こ + う)

**C3.** 1. おちゃ — "tea" ・ 2. かいしゃ — "company / workplace" ・ 3. でんしゃ — "train" ・ 4. きょう — "today" ・ 5. りょこう — "trip / travel"

## Section D

**D1.** ア [a] ・ ク [kɯ] ・ ソ [so] ・ ネ [ne] ・ ヒ [çi] ・ マ [ma] ・ ユ [jɯ] ・ ロ [ɾo] ・ ン [n] ・ ヲ [o]

**D2.** 1. シ [shi] — strokes enter from the left, low/horizontal marks, written bottom-to-top; ツ [tsu] — marks near the top, vertical, written top-to-bottom. ・ 2. ソ [so] — short stroke vertical, long stroke from the top; ン [n] — short stroke flat, long stroke sweeps up from the bottom-left. ・ 3. ロ [ro] — closed box; コ [ko] — open on the right. ・ 4. ク [ku] — two strokes; ケ [ke] — adds a vertical stroke. ・ 5. ウ [u] — has the top tick; ワ [wa] — no top tick, inner hook.

**D3.** 1. バス — "bus" ・ 2. テレビ — "television" ・ 3. パン — "bread" ・ 4. ゲーム — "game" ・ 5. ニュース — "news" ・ 6. シャツ — "shirt" ・ 7. ジュース — "juice"

## Section E

**E1.** 1. コーヒー — source "coffee" — meaning "coffee" ・ 2. ホテル — source "hotel" — "hotel" ・ 3. レストラン — source "restaurant" — "restaurant" ・ 4. メール — source "(e-)mail" — "email" ・ 5. チョコレート — source "chocolate" — "chocolate"

**E2.** 1. パーティー — ティ ("ti") ・ 2. ファイル — ファ ("fa") ・ 3. ウェブ — ウェ ("we") ・ 4. ジェット — ジェ ("je") ・ 5. チェック — チェ ("che")

**E3.** 1. コーヒー — 4 morae (コ ー ヒ ー) ・ 2. ビール — 3 morae (ビ ー ル) ・ 3. ケーキ — 3 morae (ケ ー キ) ・ 4. コンピューター — 6 morae (コ ン ピュ ー タ ー)

**E4.** 1. ミルク ← "milk" (ウ inserted after k) ・ 2. ストライク ← "strike" (vowels inserted in the cluster) ・ 3. ベッド ← "bed" (オ inserted after d, with っ) ・ 4. アルバイト ← German *Arbeit* (not English) ・ 5. スマホ ← clipped "smartphone" (スマート + ホン)

## Section F

**F1.** 1. おはよう ございます — "good morning" (polite) ・ 2. こんにちは — "hello / good day" ・ 3. こんばんは — "good evening" ・ 4. ありがとう ございます — "thank you" (polite) ・ 5. すみません — "excuse me / sorry" ・ 6. さようなら — "goodbye" ・ 7. いただきます — "(said before eating) — I gratefully receive this meal"

**F2.** No fixed answer — log your measured mora/min in `progress/progress.md`. Below 40: repeat drills, do not advance to Module 01.
