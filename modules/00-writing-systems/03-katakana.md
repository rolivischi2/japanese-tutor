# Katakana

Katakana is the **second kana script**. Here is the good news: it encodes **exactly the same sound system** as hiragana — the same gojūon grid, the same vowels, the same dakuten/handakuten and yōon rules. So katakana is *not* a new language layer. It is only a new set of **shapes** for sounds you already know. That makes it faster to learn than hiragana was.

Seven days, roughly two rows per day. Use the **Tofugu katakana mnemonics** (tofugu.com/japanese/learn-katakana) — same picture-story method as for hiragana; do not reinvent it.

## What katakana is for

Hiragana writes native Japanese words and all grammar. Katakana has a narrower job:

1. **Loanwords** from other languages — コーヒー (coffee), テレビ (television), インターネット (internet). This is the big one and the focus of `04`.
2. **Foreign names** — personal and place names: スイス (Switzerland), ハンガリー (Hungary), ローランド (the name "Roland").
3. **Onomatopoeia**, **emphasis** (like italics), scientific names of plants/animals, and stylistic effect (signage, branding).

For you, learning loanwords means a lot of vocabulary you *already know* in English/German is suddenly readable — once you can decode the katakana and adjust for Japanese pronunciation. `04` is dedicated to exactly that.

## Why katakana feels harder at first (and why that fades)

Two reasons learners stumble:
- Katakana shapes are **more angular and more similar to each other** than hiragana — シ/ツ and ソ/ン are the classic confusable pairs (see below).
- It is **used less often** than hiragana, so it gets less incidental review. Counter this with deliberate realkana.com drilling.

The shape-similarity problem is real but small, and the table below flags every pair worth a second look.

## The katakana gojūon — base table

Same a–i–u–e–o vowel order, same rows as hiragana.

|  | a | i | u | e | o |
|---|---|---|---|---|---|
| — (vowels) | ア | イ | ウ | エ | オ |
| k | カ | キ | ク | ケ | コ |
| s | サ | シ | ス | セ | ソ |
| t | タ | チ | ツ | テ | ト |
| n | ナ | ニ | ヌ | ネ | ノ |
| h | ハ | ヒ | フ | ヘ | ホ |
| m | マ | ミ | ム | メ | モ |
| y | ヤ | (イ) | ユ | (エ) | ヨ |
| r | ラ | リ | ル | レ | ロ |
| w | ワ | — | — | — | ヲ |
| n (final) | ン | | | | |

ヲ, like hiragana を, is the object particle and is almost never seen in katakana in practice — recognise it and move on.

## Look-alikes — drill these deliberately

The confusable pairs. Spend real time here; mixing them up corrupts loanword reading.

| Pair | How to tell them apart |
|---|---|
| **シ [shi] vs ツ [tsu]** | シ: strokes come in from the **left side**, written roughly **bottom-to-top**; the two short marks are stacked more **horizontally**, low. ツ: short marks sit near the **top**, more **vertical**, written **top-to-bottom**. Mnemonic: ツ "tsu" has its dots up like the *two* of "tsu". |
| **ソ [so] vs ン [n]** | ソ: short stroke is more **vertical**, the long stroke sweeps from **top**. ン: short stroke is more **horizontal/flat**, long stroke sweeps **up from the bottom-left**. ン "n" sweeps **n**orth-east. |
| **ク [ku] vs ケ [ke] vs タ [ta]** | ク is the simplest (two strokes). ケ adds a vertical stroke. タ has an extra short stroke crossing inside. |
| **ロ [ro] vs コ [ko]** | ロ is a **closed box** (4 sides). コ is **open on the right** (3 sides). |
| **ナ [na] vs メ [me] vs ヌ [nu]** | ナ is a simple cross. メ crosses with two diagonal sweeps. ヌ adds a stroke to メ-like shape. |
| **ウ [u] vs ワ [wa] vs フ [fu]** | ウ has a top tick (the dakuten-style mark up top). ワ and フ have no top tick; ワ has a small inner hook, フ is a single bent stroke. |

Tofugu's mnemonics address most of these directly. realkana.com lets you drill *only* the confusable rows — use that.

## Katakana dakuten and handakuten

Identical rules to hiragana — same ゛ and ゜ marks, same k→g, s→z, t→d, h→b, h→p.

| Base | + dakuten / handakuten |
|---|---|
| カ キ ク ケ コ | ガ ギ グ ゲ ゴ |
| サ シ ス セ ソ | ザ ジ ズ ゼ ゾ |
| タ チ ツ テ ト | ダ ヂ ヅ デ ド |
| ハ ヒ フ ヘ ホ | バ ビ ブ ベ ボ (dakuten) / パ ピ プ ペ ポ (handakuten) |

Same yotsugana note as hiragana: ジ/ヂ are homophones, ズ/ヅ are homophones — ジ and ズ are the standard spellings.

Example words:
- ゲーム — "game"
- テレビ — "television"
- バス — "bus"
- パン — "bread" (a loanword, from Portuguese *pão*)

## Katakana yōon

Same mechanism as hiragana: an i-column katakana + small ャ ュ ョ, read as one mora.

| Base | + ャ | + ュ | + ョ |
|---|---|---|---|
| キ | キャ | キュ | キョ |
| シ | シャ | シュ | ショ |
| チ | チャ | チュ | チョ |
| ニ | ニャ | ニュ | ニョ |
| ヒ | ヒャ | ヒュ | ヒョ |
| ミ | ミャ | ミュ | ミョ |
| リ | リャ | リュ | リョ |
| ギ | ギャ | ギュ | ギョ |
| ジ | ジャ | ジュ | ジョ |
| ビ | ビャ | ビュ | ビョ |
| ピ | ピャ | ピュ | ピョ |

Example words:
- ニュース — "news"
- シャツ — "shirt"
- ジュース — "juice"

Katakana also has an **extended yōon set** for foreign sounds that the native grid cannot spell — ファ, ティ, ウィ, ジェ and friends. Those plus the long-vowel mark ー belong to `04`, the loanword chapter.

## End-of-module checkpoint

After Day 14 you can read **both** kana scripts: hiragana fully (`01`, `02`) and katakana fully (this file). Day 14 ends with the **final 40 mora/min speed test combining hiragana and katakana** — see `00-overview.md`. Drill on realkana.com with every option ticked.

Before you can call katakana finished, do `04` — loanword traps — because raw katakana decoding is not enough to *read loanwords* without knowing the ー mark and the foreign-sound combinations. Vocabulary is collected in `module-vocab.json`.
