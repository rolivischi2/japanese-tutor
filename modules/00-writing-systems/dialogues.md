# Module 00 — Dialogues

Module 00 has **no grammar**, so there are no real dialogues here — only a small set of **fixed greetings and set phrases** written purely in kana. Their job is *reading practice*: real Japanese, in real kana, that you can decode and say aloud. Treat them as sight-reading targets, not as grammar to analyse — the grammar (why です ends a sentence, what は does) starts in Module 01.

Each item: the kana line, then an English gloss. Read the kana aloud first, then check the gloss. All of these also appear in `module-vocab.json` and in `exercises.md` Section F.

## Greetings — by time of day

```
おはよう ございます
```
Good morning. (Polite. Casual short form: おはよう.)

```
こんにちは
```
Hello. / Good day. (Daytime. Note: the final は here is the topic-particle は, pronounced [wa] — a spelling quirk of this fixed phrase. You meet that particle properly in Module 01.)

```
こんばんは
```
Good evening. (Same final-は pronunciation note as こんにちは.)

```
おやすみなさい
```
Good night. (Said before sleeping. Casual short form: おやすみ.)

## Meeting and parting

```
さようなら
```
Goodbye. (Somewhat formal / final-feeling; not used casually among friends every day.)

```
はじめまして
```
How do you do. / Nice to meet you. (Said the first time you meet someone — literally "for the first time".)

```
よろしく おねがいします
```
Please treat me well. / I look forward to working with you. (A set social phrase with no clean English equivalent; said on meeting someone or asking a favour.)

## Thanks and apology

```
ありがとう ございます
```
Thank you. (Polite. Casual short form: ありがとう.)

```
すみません
```
Excuse me. / Sorry. / (also used to get someone's attention, e.g. a waiter.)

```
ごめんなさい
```
I'm sorry. (An apology; more personal/contrite than すみません. Casual short form: ごめん.)

## Around meals

```
いただきます
```
Said before eating — roughly "I gratefully receive this meal." No English equivalent; said by the person about to eat.

```
ごちそうさまでした
```
Said after eating — roughly "thank you for the meal." Casual short form: ごちそうさま.

## A two-line exchange

The closest thing to a dialogue at this stage — two fixed phrases in sequence, the kind of exchange you would have meeting someone:

```
A: はじめまして。
B: はじめまして。よろしく おねがいします。
```
A: How do you do.
B: How do you do. I look forward to getting to know you.

## How to use this file

1. Read each kana line aloud **without** looking at the gloss — this is the sight-reading drill.
2. Check the gloss; confirm you decoded correctly.
3. Add these to your Anki kana/vocab review so they become automatic.
4. Use them for real from Day 1 — greet your tutor or conversation partner with おはよう ございます, say いただきます before lunch. Spaced real use beats flashcards.

Full grammar-bearing dialogues begin in **Module 01**. The vocabulary above is catalogued in `module-vocab.json`.
