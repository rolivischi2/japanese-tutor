Speech

Read a phrase aloud. Microsoft’s pronunciation engine scores each word and the overall delivery. Powered by Azure Speech (free tier covers ~5 hours/month).

Setup required. The pronunciation service isn’t configured for this deployment yet.
Setup steps (~5 min, free)
  1. Create a free Azure account (no credit card needed for the F0 tier).
  2. In the Azure portal: Create a resource → Speech → pricing tier F0 (free; 5 hours/month).
  3. Open the resource → Keys and Endpoint → copy Key 1 and the Region (e.g. westeurope).
  4. In Vercel project settings → Environment Variables, add SPEECH_KEY and SPEECH_REGION.
  5. Trigger a redeploy (any git push works).
