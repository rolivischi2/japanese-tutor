# Yomitan Setup

Install Yomitan in Firefox, Chrome, or Edge; add the JMdict (Jitendex), KANJIDIC, Kanjium pitch accent, and JPDB frequency dictionaries; and connect it to Anki via AnkiConnect pointing at the `Roland::Mining` deck.
