# Anki Setup

Install Anki on Mac from apps.ankiweb.net; enable FSRS scheduler and add AnkiConnect (add-on 2055492159), Japanese Support, and optional Kanji Grid add-ons; import the decks produced by `tools/export_to_anki.py`.
